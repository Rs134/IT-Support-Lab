# IT Support Lab

This is a hands-on IT support lab I am building to get more comfortable troubleshooting common computer and user problems.

The goal is to practice working through issues step by step, understand the tools being used, and document how I found and fixed each problem.

## What I'm Learning

* Windows troubleshooting
* Basic hardware troubleshooting
* Software and application issues
* File and folder permissions
* Network connectivity
* DNS and basic networking
* Windows settings and utilities
* Command Prompt
* Troubleshooting methods
* Technical documentation
* User support

## Lab Environment

The lab is mainly done using:

* Windows VM
* UTM
* Command Prompt
* Windows built-in troubleshooting tools
* Test files and folders

## How I Approach Problems

For each lab, I try to follow a simple troubleshooting process:

1. Understand the problem
2. Reproduce or check the issue
3. Gather information
4. Test possible causes
5. Make a fix
6. Test again
7. Document what happened

I'm trying to focus on understanding **why** I'm running a particular test instead of just memorizing commands.

## Ticket Documentation

Each ticket includes:

* Problem description
* Environment
* Troubleshooting steps
* Results from each step
* Root cause
* Resolution
* Verification
* Tools used
* Notes

I document the steps in the order they were actually performed so I can look back and understand how I reached the solution.

## Screenshots

Screenshots are included when they help show the troubleshooting process.

Before sharing screenshots publicly, I remove or hide information such as:

* Username
* Computer name
* IP address
* MAC address
* Personal files
* Passwords or other sensitive information

## Final Remarks

The goal is to build experience with common issues that could come up in a Help Desk or Desktop Support position.
